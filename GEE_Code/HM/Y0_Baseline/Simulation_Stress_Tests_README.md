# Simulation Stress Tests

`Simulation_Stress_Tests.R` runs the secondary simulation checks for the
conditional-first hurdle-model manuscript analysis. Run it from the repository
root:

```sh
Rscript GEE_Code/HM/Y0_Baseline/Simulation_Stress_Tests.R
```

The script reads corrected-surrogate calibration values from:

```text
GEE_Code/HM/Y0_Baseline/Data_Results_Cond_New_Surrogate/Data_Like_Calibration/
```

and writes current stress-test outputs under:

```text
GEE_Code/HM/Y0_Baseline/New_Surrogate_Results/Sim_Results_Cond/Stress_Tests/
```

## Run Toggles

The user-configurable block at the top of `Simulation_Stress_Tests.R` controls
which sections run:

- `run_response_stress_n400`: correct-HM stress tests at `n = 400`.
- `run_response_stress_n1000`: correct-HM stress tests at `n = 1000`.
- `run_zero_prediction`: all-count Poisson/NB zero-prediction diagnostics.
- `run_response_misspecification`: response-model misspecification check.

The current default is to rerun only the zero-prediction diagnostics, because
the all-count NB diagnostic was updated.

## All-Count Poisson/NB Zero Prediction

This diagnostic asks whether ordinary one-part count models can reproduce the
zero proportions generated by the hurdle model.

For each simulated dataset:

1. Generate the long-format SMART data from the hurdle model.
2. Keep the outcome `Y` exactly as generated, including both zeros and positive
   counts.
3. Fit an ordinary Poisson regression to all rows using the same unified
   covariate structure used in the simulation diagnostics.
4. Predict each row's Poisson mean, `mu_i`.
5. Convert each mean to a row-level zero probability using
   `dpois(0, lambda = mu_i)`.
6. Fit an ordinary Negative Binomial regression to all rows.
7. Predict each row's NB mean and estimated dispersion/size parameter.
8. Convert each row to an NB zero probability using
   `dnbinom(0, size = theta, mu = mu_i)`.
9. Average the row-level zero probabilities overall and by month.

The Poisson zero prediction can be essentially zero when the fitted all-count
means are large. For example, a Poisson mean around 10 implies
`P(Y = 0) = exp(-10)`, which is nearly zero. The all-count NB model can predict
more zeros because it allows overdispersion, but it still uses one count process
rather than separately modeling zero versus positive-count outcomes.

The zero-prediction plot now focuses on:

- Observed zero proportion.
- Hurdle-model binary-component prediction.
- All-count Poisson prediction.
- All-count Negative Binomial prediction.

Positive-only Poisson/NB diagnostic columns may still be written for audit, but
they are not the focus of the current plot or manuscript interpretation.

## Current Zero-Prediction Scenarios

The zero-prediction rerun covers:

- sample sizes: `n = 400`, `n = 1000`;
- zero-inflation targets: `15%`, `30%`, `60%`;
- correlation structure: AR(1);
- working correlation parameter: `rho = 0.5`;
- iterations: `1000`.
