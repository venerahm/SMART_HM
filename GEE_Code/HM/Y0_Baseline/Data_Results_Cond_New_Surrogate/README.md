# Current Corrected-Surrogate Data Results

This folder stores the current conditional hurdle-model data-application
outputs for the chapter 3 `Y0_Baseline` analysis.

These results use the corrected surrogate month-one and month-two alcohol
outcomes. Weekly total drinks are calculated as drinking days multiplied by
typical drinks per drinking day; weeks with zero drinking days are assigned zero
drinks. Monthly surrogates are computed as the mean weekly total in the relevant
four-week window multiplied by `30 / 7` and rounded.

Generated by:

```text
GEE_Code/HM/Y0_Baseline/HM_Data_Application_Conditional.R
GEE_Code/HM/Y0_Baseline/Derive_Data_Like_Simulation_Values.R
```

Important contents:

- `Outcome_Proportions_By_Time_Conditional.csv`: observed zero and positive
  outcome summaries by time.
- `DTR_Estimates_Conditional_Month_4.csv`: month-four DTR-level estimates.
- `DTR_Estimates_By_Model_Conditional_Month_4.csv`: month-four estimates split
  by binary and truncated-count model component.
- `DTR_Trajectories_Conditional_PostSplit.csv`: post-split DTR trajectories.
- `dtr_number_key.csv`: DTR numbering and treatment-path key.
- `figures/`: manuscript and presentation figures saved as PNG and EPS. Files
  ending in `_ppt` are colored presentation versions.
- `Data_Like_Calibration/`: current data-like simulation calibration values.

These files are generated results, not source code.
