# Current Corrected-Surrogate Simulation Results

This folder stores the current simulation outputs for the chapter 3
conditional-first hurdle-model analyses using the corrected surrogate
data-application calibration.

Generated by:

```text
GEE_Code/HM/Y0_Baseline/Manuscript_Simulation.R
GEE_Code/HM/Y0_Baseline/Simulation_Stress_Tests.R
```

The simulations read calibration values from:

```text
GEE_Code/HM/Y0_Baseline/Data_Results_Cond_New_Surrogate/Data_Like_Calibration/
```

Expected structure:

- `Sim_Results_Cond/Manuscript_Primary/niter_5000/`: primary manuscript
  simulation output.
- `Sim_Results_Cond/Stress_Tests/Response_Stress_n400/niter_5000/`:
  response-rate and zero-inflation stress tests for `n = 400`.
- `Sim_Results_Cond/Stress_Tests/Response_Stress_n1000/niter_5000/`:
  response-rate and zero-inflation stress tests for `n = 1000`, when run.
- `Sim_Results_Cond/Stress_Tests/Response_Misspecification/niter_5000/`:
  simulations where response is generated from `A1 + Y0 + BLDEPPOS` but the
  working response model omits `BLDEPPOS`.
- `Sim_Results_Cond/Stress_Tests/Zero_Prediction/niter_1000/`: diagnostics
  comparing observed zero proportions with zeros implied by one-part Poisson and
  Negative Binomial count models.

These files are generated results, not source code.
