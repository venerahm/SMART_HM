# Stress Tests

`scripts/run_stress_tests.R` runs secondary simulation diagnostics for the
conditional-first hurdle-model SMART analysis. Run it from the repository root:

```bash
Rscript scripts/run_stress_tests.R
```

The script reads public design inputs from `config/simulation_design.R` and
writes generated outputs under `results/stress_tests/` by default.

## Run Toggles

The user-configurable block at the top of `scripts/run_stress_tests.R` controls
which sections run:

- `run_response_stress_n400`: correct-HM stress tests at `n = 400`.
- `run_response_stress_n1000`: correct-HM stress tests at `n = 1000`.
- `run_zero_prediction`: all-count Poisson/NB zero-prediction diagnostics.
- `run_response_misspecification`: response-model misspecification check.

The current default reruns only the zero-prediction diagnostics.

## All-Count Poisson/NB Zero Prediction

This diagnostic asks whether ordinary one-part count models can reproduce the
zero proportions generated by the hurdle model.

For each simulated dataset:

1. Generate long-format SMART data from the hurdle model.
2. Keep the outcome `Y` exactly as generated, including zeros and positive
   counts.
3. Fit an ordinary Poisson regression to all rows using the unified covariate
   structure used in the simulation diagnostics.
4. Convert each predicted Poisson mean to a row-level zero probability.
5. Fit an ordinary negative binomial regression to all rows.
6. Convert each predicted negative binomial mean and dispersion estimate to a
   row-level zero probability.
7. Average row-level zero probabilities overall and by month.

The plot focuses on observed zero proportions, hurdle-model binary-component
predictions, all-count Poisson predictions, and all-count negative binomial
predictions.

## Current Zero-Prediction Scenarios

The default zero-prediction rerun covers:

- sample sizes: `n = 400`, `n = 1000`
- zero-inflation targets: `15%`, `30%`, `60%`
- correlation structure: AR(1)
- working correlation parameter: `rho = 0.5`
- iterations: `1000`

For a quick smoke test:

```bash
SMART_HM_ZERO_PREDICTION_NITER=1 Rscript scripts/run_stress_tests.R
```
